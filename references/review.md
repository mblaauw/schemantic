# Review questions

Ask these with the rendered PNG in front of you. Lint checks geometry; these check whether the plate works.
Every "no" is a change to the spec.

1. **Message.** Covering the subtitle, does the picture alone support the title's claim?
2. **Path.** Can a reader follow the arrows from where the story starts to where it ends, without a jump?
3. **Colour.** Does every role colour mean the same thing as in the legend (platform, data, external, actor, and any theme role)?
4. **Balance.** Is any panel visibly emptier or fuller than the others? (Lint warns below 60% density.)
5. **Words.** Is every name a noun the reader knows, and every note specific to this system?
6. **Open ends.** Does each warning chip ask a real, still-open question, and does each principle state a
   decision someone could check?
7. **Series.** If this is one part of a series, do the same things carry the same names and colours as on the
   other parts?
