# Ontwerpnotitie klantportaal (fictief)

Het klantportaal is een webapplicatie voor zakelijke klanten. Klanten loggen in via de identity provider.
Het portaal haalt facturen op uit het financiële systeem en contracten uit het contractbeheer.
Wijzigingen in contactgegevens gaan naar het CRM. Alle verzoeken lopen via de API gateway.
Besluit: het portaal slaat zelf geen klantgegevens op.
Open vraag: moeten klanten ook documenten kunnen uploaden?
